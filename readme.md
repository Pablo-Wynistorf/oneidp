# Free and opensource openid-connect and oauth2 provider

Use predeployed provider under: https://oneidp.ch

This loginapp can be placed in front of practically ever application to authenticate their users. After a successful login, the api sends back a session cookie to authenticate the user.

The app is build with express js and a mongodb backend. 
For mail delievery we use MailRift. Create a account to get the api key. https://mailrift.io

For alerting and log we use discord webhook. Create a channel in a discord server and get the webhook url. https://discord.com

## Use this oidc provider

# Deployment on AWS (Terraform)

ONEIDP deploys as a serverless stack: the Express app runs in a single Lambda
function behind an API Gateway HTTP API and a CloudFront distribution, with the
React frontend served from S3 through the same distribution.

```
Viewer ──► CloudFront ──► API Gateway (HTTP API) ──► Lambda (Express app)
                                                          │
                                                          ├─► MongoDB (MONGODB_URI)
                                                          └─► Redis   (REDIS_URI)
```

Prerequisites: Terraform >= 1.5, configured AWS credentials, Node.js + npm on
the machine running `terraform apply`, and a publicly reachable MongoDB and
Redis instance (e.g. MongoDB Atlas, Redis Cloud).

1.) Clone the github repo

```bash
git clone https://github.com/Pablo-Wynistorf/oneidp.git && cd oneidp
```

2.) Fill in your values

```bash
cd terraform
cp terraform.tfvars.example terraform.tfvars   # then edit values
```

`mongodb_uri`, `redis_uri` and `admin_emails` are required. MailRift, Discord
monitoring, Google/GitHub social login and a custom domain are optional. The
RS256 JWT keypair is generated by Terraform, so no keys need to be supplied.

3.) Deploy

```bash
terraform init
terraform apply
```

The apply builds the Lambda bundle from `../src` and the frontend from
`../frontend`, uploads both, and prints the public URL as the `app_url` output.

Deployment details, custom domain setup and caching notes live in
[`terraform/README.md`](./terraform/README.md).

## Local frontend development

cd frontend
